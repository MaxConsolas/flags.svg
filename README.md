# Country Flags SVG Collection

A collection of country flag SVG images extracted from Noto Color Emoji.

## Overview

This repository contains SVG files of country flags named using ISO 3166-1 Alpha-2 country codes (e.g., `US.svg`, `RU.svg`, `GB.svg`).

## Special Flags

The collection also includes special regional flags:
- `GB-ENG.svg` - England
- `GB-SCT.svg` - Scotland  
- `GB-WLS.svg` - Wales

## Source

All flags are sourced from [Noto Color Emoji](https://fonts.google.com/noto/specimen/Noto+Color+Emoji).
